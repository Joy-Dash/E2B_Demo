# E2B Demo v2

## 使用方式
1. 請先將 ZIP 解壓縮。
2. 打開 `index.html`。
3. 不要直接在 ZIP 壓縮檔裡雙擊 HTML，瀏覽器可能讀不到 `css/style.css` 和 `js/app.js`，畫面會變成沒有樣式的原始 HTML。

## 檔案結構
- `index.html`：Demo 入口
- `css/style.css`：從原 HTML 抽出的所有 CSS
- `js/app.js`：從原 HTML 抽出的所有 JavaScript

## E2B Prototype v4
本版重點是統一創意與文案中心所有生成結果的操作按鈕與 AI調整 Modal。

## 創意與文案中心定位
- 廣告素材：產生可貼到 Google Ads / Meta Ads Manager 後台投放的付費素材。
- 社群內容：產生可發布或排程到 Meta Business Suite、IG App、TikTok Studio、LINE OA 或第三方排程工具的自然內容包。

## 廣告素材新版流程
1. 選擇投放平台。
2. 選擇廣告目的。
3. 選擇素材型態：圖文廣告、影片廣告、圖文 + 影片、僅文案。
4. 引用既有資料：商品、社群內容、活動、品牌資料。
5. 選擇要消耗 AI 產出的素材：圖文素材、影音素材。

廣告素材不提供目標受眾、賣點、優惠或其他限制等手動輸入補充區，避免使用者在前台重複填寫後台或資料庫已有資訊。
引用商品資料時可搜尋商品名稱、SKU、分類或來源平台。

## AI Token 消耗設計
使用者需要能決定本次 AI token 要花在哪些素材上。

- 只選 `圖文素材`：產出標題包、文案包、圖片方向。
- 勾選 `影音素材`：額外產出影片腳本 / 分鏡。
- 平台目標建議與 AI 推薦素材組合作為輔助判斷輸出。
